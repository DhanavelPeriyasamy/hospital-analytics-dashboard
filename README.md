# Hospital Analytics & Operational Intelligence

An end-to-end healthcare operations analytics project built to help hospital administrators understand patient demand, capacity, throughput, and department-level performance. It combines reproducible synthetic data generation, Python data-quality checks, analytical SQL, and a Power BI dashboard specification.

> **Data & safety:** The included generator creates synthetic demonstration records. They are not real patient records and must not be interpreted as clinical evidence. Do not upload identifiable or protected health information to this repository.

## Business objectives
- Monitor encounter volumes, admissions, discharges, and monthly demand.
- Compare department workload and average length of stay (ALOS).
- Track bed occupancy and identify periods of capacity pressure.
- Explore discharge turnaround and readmission indicators.
- Present operational findings with clear definitions and caveats.

## KPI catalogue
| KPI | Definition |
|---|---|
| Encounters | Distinct count of encounter IDs |
| Admissions / discharges | Count of admission / discharge events |
| ALOS | Average discharge date minus admission date, in days |
| Bed occupancy % | Occupied bed-days / available bed-days × 100 |
| 30-day readmission rate | Eligible discharges followed by a new encounter within 30 days / eligible discharges |
| Discharge turnaround | Discharge timestamp minus discharge order timestamp |

These are portfolio-demo definitions. Confirm local metric definitions and denominator rules before real operational use.

## Quick start
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/generate_data.py
python src/validate_data.py
```
The generator writes `data/departments.csv`, `data/patients.csv`, and `data/encounters.csv`. Load these tables into MySQL using the column definitions in the SQL script, or import them directly into Power BI.

## Power BI report design
1. **Executive overview:** encounter count, admissions, discharges, ALOS, occupancy.
2. **Patient flow:** monthly admission/discharge trends, admission type, discharge disposition.
3. **Department performance:** volume, ALOS, readmission rate by department.
4. **Capacity & operations:** daily occupied beds, occupancy %, discharge turnaround.

Use a Date dimension and a star-schema model. Recommended slicers: date, department, admission type, and discharge disposition. Detailed relationships and DAX are in `powerbi/`.

## Quality controls
The validation script checks key uniqueness, missing values, valid foreign keys, date ordering, and non-negative length of stay. Review its output before analysis.

## Limitations & next steps
This repository provides reproducible synthetic data, SQL, DAX, and a dashboard build specification. A `.pbix` file must be authored in Power BI Desktop; it is not generated by the Python pipeline. Read `docs/analysis_plan.md` before interpreting results.
